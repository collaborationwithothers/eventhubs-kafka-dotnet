# Not supported on our Event Hubs Premium namespace: C08 KIP-848 subscribe

Not supported on our Event Hubs Premium namespace on 2026-10-28: the namespace did not advertise a KIP-848 ConsumerGroupHeartbeat API version usable by librdkafka 2.16.0, so a consumer with group.protocol=consumer did not join and this unsupported-API path raised no application error. This is a source-supported inference from pod logs; the published C1 class is "no assignment and no error within the window". The proposed verdict is undocumented under Hari's C08-only waiver, and three of the five C1 repeats remain incomplete.


The log occurrence is measured. The API-advertisement explanation is a source-supported inference about a version usable by this client: [librdkafka v2.16.0 request code](https://github.com/confluentinc/librdkafka/blob/v2.16.0/src/rdkafka_request.c#L2298-L2306) checks heartbeat version 1 and returns after marking the coordinator dead when unavailable. The [coordinator path](https://github.com/confluentinc/librdkafka/blob/v2.16.0/src/rdkafka_cgrp.c#L902-L915) logs and re-queries without raising an application error. The [fatal-error branch](https://github.com/confluentinc/librdkafka/blob/v2.16.0/src/rdkafka_cgrp.c#L3402-L3409) belongs to the response handler, not this unsent-request path.

The complete C1 repeats record `no_outcome`. Debug lines supply no application-error code for them, and the incomplete repeats acquire no outcome class. The coordinator SASL transport FAIL cause is unknown; its final-run occurrences coincide with the incomplete repeats but do not establish causality. No further investigation, run or spend follows. Raw captures and a wire ApiVersions response are absent from the public artifacts. This evidence does not establish support across other namespaces, dates or client versions. The cited [Microsoft configuration](https://learn.microsoft.com/en-us/azure/event-hubs/apache-kafka-configurations), [developer](https://learn.microsoft.com/en-us/azure/event-hubs/apache-kafka-developer-guide) and [troubleshooting](https://learn.microsoft.com/en-us/azure/event-hubs/apache-kafka-troubleshooting-guide) guidance supplies no KIP-848 support or non-support statement (read 2026-10-28).
